# コミット対象ファイルの取得

以下のStepに従い、コミット対象のファイル情報を取得する

## 機密ファイルの判定基準

Step1およびStep2でファイルパス一覧を取得した直後、変更内容を取得する前に、以下のパターンに一致するファイルが含まれるか確認する

判定はファイルパスのみで行い、ファイルの中身は読み取らない

| 分類 | パターン |
| ---- | -------- |
| 環境変数ファイル | `.env` で始まるファイル、`.envrc`、`.dev.vars` |
| 秘密鍵 | `*.pem`、`*.key`、`*.p12`、`*.pfx`、`*.jks`、`*.keystore`、`id_rsa`、`id_ecdsa`、`id_ed25519` |
| 認証情報 | `credentials`、`credentials.json`、`client_secret*.json`、`service-account*.json`、`*secret*.json`、`secrets.yml`、`secrets.yaml` |
| ツール設定 | `.npmrc`、`.pypirc`、`.netrc`、`.pgpass`、`.my.cnf`、`.aws/credentials`、`.ssh/` 配下のファイル |
| インフラ状態 | `*.tfvars`、`*.tfstate`、`*.tfstate.backup` |

`.env.example`、`.env.sample`、`.env.template`、`*.pub` のようにサンプルや公開鍵であることが明らかなファイルは対象外とする

該当するファイルがある場合は、以下のメッセージをユーザーに伝えて処理を終了

「機密情報を含む可能性のあるファイルを検出しました: `<該当ファイルパス>`
誤ってコミットするリスクを避けるため、処理を中断しました
コミットが必要な場合は `.gitignore` への追加、またはコミット対象からの除外を行ったうえで再実行してください」

該当するファイルがない場合は、後続のStepへ進む

## Step1: indexにある変更内容を取得

```bash
# 1. ファイルパスの一覧を取得
git diff --cached --name-only
```

取得したファイルパス一覧を「機密ファイルの判定基準」で確認する

該当ファイルがなければ、変更内容を取得する

```bash
# 2. ファイルの変更内容を取得
git diff --cached
```

1. 出力がある場合: 変更元を `staged` として記録し、Step3へ進む
2. 出力がない場合: Step2へ進む

## Step2: working treeにある変更内容を取得

### 追跡済みファイルの変更内容を取得

```bash
# 追跡済みファイルパスの一覧を取得
git diff --name-only
```

取得したファイルパス一覧を「機密ファイルの判定基準」で確認する

該当ファイルがなければ、変更内容を取得する

```bash
# 追跡済みファイルの変更内容を取得
git diff
```

### 未追跡ファイルの変更内容を取得

```bash
# 未追跡ファイルパスの一覧を取得
git ls-files --others --exclude-standard
# 未追跡ファイルの件数を取得
git ls-files --others --exclude-standard | wc -l
```

取得したファイルパス一覧を「機密ファイルの判定基準」で確認する

未追跡ファイルの件数を確認

1. 20件を超える場合は、以下のメッセージをユーザーに伝えて処理を終了

   「未追跡ファイルが N 件あります。誤って大量のファイルをコミットするリスクを避けるため、処理を中断しました」

2. 20件以下の場合は、各未追跡ファイルの変更内容を取得

```bash
# 各未追跡ファイルの変更内容を取得 (差分ありの場合はexit code 1でエラー判定になるため || true で抑制すること)
git diff --no-index /dev/null <file> || true
```

変更元を `workspace` として記録し、Step3へ進む

## Step3: 以下の情報を整理し、後続の処理に利用

- 変更元の判定 (`staged` または `workspace`)
- 変更対象のファイルパス一覧
- 各ファイルの変更内容
