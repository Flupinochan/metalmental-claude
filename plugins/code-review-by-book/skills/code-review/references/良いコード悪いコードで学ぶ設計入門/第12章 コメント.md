## NG ごまかすためのコメント

変数名や関数名から意図や処理内容が分からない場合にコメントアウトで補足するのは良くない

変数名や関数名を見直すこと

## OK 目的や今後コード(仕様)変更する時の注意事項として読み手に伝えるためのコメント

```typescript
async function clearCache(key: string): Promise<void> {
  try {
    await cache.delete(key);
  } catch (error) {
    // キャッシュは高速化用で処理を止める必要がないためエラーを握りつぶし異常通知はしない
    logger.warn("cache delete failed", { key, error });
  }
}
```
