## NG getter/setterの利用 (尋ねるな、命じろ)

1つのクラスにデータとそれを操作するメソッドを定義するカプセル化が意味をなさなくなるため

JSONシリアライザなどのライブラリの仕様上必要な場合はOK

```java
public class Person {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String newName) {
        name = newName;
    }
}
```

## NG 取得と変更を同時に行うメソッド

```java
int gainAndGetPoint() {
    point += 10;
    return point;
}
```

## OK コマンド・クエリ分離

インスタンス変数の 変更 (コマンド) と 取得 (クエリ) のどちらか一方のみ行うようにメソッドを設計すること

```java
// コマンド
void gainPoint() {
    point += 10;
}

// クエリ
int getPoint() {
    return point;
}
```

## OK 意図が分かる独自の型で返却

```java
class Price {
    Price add(final Price other) {
        final int added = amount + other.amount;
        return new Price(added);
    }
}

// 例: 金額ごとにDiscountedPrice、DeliveryPriceなど細かく分けるとなおよい
Price price = productPrice.add(otherPrice);
DiscountedPrice discountedPrice = new DiscountedPrice(price);
DeliveryPrice deliveryPrice = new DeliveryPrice(discountedPrice);
```
