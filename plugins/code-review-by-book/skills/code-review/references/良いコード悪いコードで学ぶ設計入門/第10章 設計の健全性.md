## NG マジックナンバー

必ず数値の意図を明示するために、数値に名前を付けて定数として定義すること

直接数値を利用して計算しない

## NG 文字列型執着

複数の値を目的ごとの変数に分けず、カンマ区切り等でひとつの変数で済ませること

目的の異なる値は、それぞれ別の変数に格納すること

```java
String title = "タイトル,255,250,240,64";
```

## NG null

nullは返さない、渡さない、代入しない、引数にしない、初期化しない

プログラミング言語にもよるが可能な限りnullは完全に非許容にすべき

## NG 例外の握り潰し

```java
try {
    reservation.add(product);
} catch (Exception e) {

}
```

## OK 異常終了させたくない場合でも必ずログを出力すること

```java
try {
    reservation.add(product);
} catch (Exception e) {
    notifyError("予約できない商品です");
}
```

## NG リフレクションの利用

不変な変数を可変に扱えてしまうので使用してはいけない
