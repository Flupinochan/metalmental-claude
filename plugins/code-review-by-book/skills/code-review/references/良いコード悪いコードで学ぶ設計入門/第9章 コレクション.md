## NG 自前でコレクションを処理

```java
boolean hasPrisonKey = false;
// itemsはList<Item>型
for (Item each : items) {
  if (each.name.equals("牢屋の鍵")) {
    hasPrisonKey = true;
    break;
  }
}
```

## OK 標準ライブラリの機能を利用

for文でコレクションを処理している場合は、標準ライブラリの機能 (メソッド) で簡潔に記載できないか検討すること

```java
boolean hasPrisonKey = items.stream().anyMatch(item -> item.name.equals("牢屋の鍵"));
```

## OK ループ処理における条件分岐ではスキップ(continue)を適切に利用すること

早期return同様に、早期continueすること

```java
for (Member member : members) {
  if (member.hitPoint == 0) continue;
  if (!member.containsState(StateType.poison)) continue;

  member.hitPoint -= 10;

  if (0 < member.hitPoint) continue;

  member.hitPoint = 0;
  member.addState(StateType.dead);
  member.removeState(StateType.poison);
}
```

## OK ループ処理における条件分岐では条件を反転し、breakを適切に利用すること

```java
int totalDamage = 0;
for (Member member : members) {
  // not条件にすることで早期break可能
  if (!member.hasTeamAttackSucceeded()) break;

  int damage = (int)(member.attack() * 1.1);

  if (damage < 30) break;

  totalDamage += damage;
}
```

## OK コレクション処理をカプセル化 (First Class Collection)

リストやマップなどのコレクションをプリミティブと見なし、それをラップした(フィールととして定義した)専用のクラスを定義

コレクション処理は様々なところで行われる可能性があり、重複処理を避けるためにカプセル化(クラスのフィールドで管理)し、振る舞いをクラスに集約

```java
// membersコレクションを管理するPartyクラス
class Party {
  static final int MAX_MEMBER_COUNT = 4;
  private final List<Member> members;

  Party() {
    members = new ArrayList<Member>();
  }

  private Party(List<Member> members) {
    this.members = members;
  }

  // 外部からのアクセス用
  // 読み取り専用(不変)にすることでロジックが別の場所で定義されることを防ぐ
  List<Member> members() {
    return members.unmodifiableList();
  }

  Party add(final Member newMember) {
    if (exists(newMember)) {
      throw new RuntimeException("既にパーティに加わっています。");
    }
    if (isFull()) {
      throw new RuntimeException("これ以上メンバーを追加できません。");
    }

    final List<Member> adding = new ArrayList<>(members);
    adding.add(newMember);
    return new Party(adding);
  }

  boolean isAlive() {
    return members.stream().anyMatch(each -> each.isAlive());
  }

  boolean exists(final Member member) {
    return members.stream().anyMatch(each -> each.id == member.id);
  }

  boolean isFull() {
    return members.size() == MAX_MEMBER_COUNT;
  }
}
```
