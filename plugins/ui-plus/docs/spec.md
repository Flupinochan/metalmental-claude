# ui-plus 仕様

テストが担保する仕様の一覧

- 各行の ID を、テスト名から参照する
- 「実装」は、仕様を実装している関数や定数の名前。名前がない処理は、ファイル名

## 1. コピーボタン (表)

回答 (`AssistantMessage`) の Markdown の表の上に、表をコピーするボタンを表示する

| ID    | 区分   | 仕様                                                                                                                                          | 実装                 |
| ----- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| UI-1  | 正常系 | 表がない1行の回答は、ボタンを出さず、文字だけで表示する                                                                                       | `register.tsx`       |
| UI-2  | 正常系 | 表がある回答は、表ごとに表の上へ `COPY TABLE` ボタンを表示する。表以外の文章は、回答の順にそのまま表示                                        | `register.tsx`       |
| UI-3  | 正常系 | 表以外の文章も、Markdown として表示する                                                                                                       | `register.tsx`       |
| UI-4  | 正常系 | 要約の回答 (`isSummary`) は、標準の描画にする                                                                                                 | `register.tsx`       |
| UI-5  | 正常系 | ボタンの幅は、端末の横幅から余白 6 (字下げ 2、枠線 2、余裕 2) を引いた幅にそろえる。横幅が分からないときは、文言のみ                          | `padLabelToWidth`    |
| LBL-1 | 正常系 | 枠線と文言は塗りつぶさない。未押下 → `COPY TABLE` (white、ポインタが乗ると indigo)、成功 → `TABLE COPIED` (green)、失敗 → `COPY FAILED` (red) | `getCopyButtonStyle` |
| LBL-2 | 正常系 | 文言は中央に置き、両側をノーブレークスペースで埋める                                                                                          | `padLabelToWidth`    |
| LBL-3 | 正常系 | 横幅が文言より狭くても、文言を切らない                                                                                                        | `padLabelToWidth`    |
| BTN-1 | 正常系 | ボタンを押すと、表の元の Markdown をそのままコピーする                                                                                        | `copyText`           |
| BTN-2 | 正常系 | コピーできたら `TABLE COPIED` を 3 秒間表示して、`COPY TABLE` に戻る                                                                          | `copyText`           |
| BTN-3 | 異常系 | コピーが断られたら `COPY FAILED` を 3 秒間表示して、理由をデバッグログに残す                                                                  | `copyText`           |
| BTN-4 | 異常系 | コピーが例外で失敗しても `COPY FAILED` を表示して、デバッグログに残す                                                                         | `copyText`           |
| BTN-5 | 正常系 | 結果は表ごとに表示する                                                                                                                        | `copyText`           |
| BTN-6 | 正常系 | 結果の表示中に押し直したら、3 秒を数え直す                                                                                                    | `storeCopyResult`    |

## 2. コピーボタン (コードブロック)

回答のコードブロックを枠線で囲み、その上にコードをコピーするボタンを表示する。言語は区別しない

| ID     | 区分   | 仕様                                                                                      | 実装                 |
| ------ | ------ | ----------------------------------------------------------------------------------------- | -------------------- |
| CODE-1 | 正常系 | コードブロックの上に `COPY CODE` ボタンを表示し、コードブロックは Markdown のまま表示する | `register.tsx`       |
| CODE-2 | 正常系 | ボタンを押すと、フェンス行を除いたコードをコピーする                                      | `copyText`           |
| CODE-3 | 正常系 | コピーできたら `CODE COPIED` を 3 秒間表示して、`COPY CODE` に戻る                        | `getCopyButtonStyle` |
| CODE-4 | 異常系 | コピーに失敗したら `COPY FAILED` を表示する                                               | `copyText`           |
| CODE-5 | 正常系 | 表とコードの結果は、別々に表示する                                                        | `copyText`           |
| CODE-6 | 正常系 | 言語によらず、コードブロックの上にボタンを表示する                                        | `register.tsx`       |
| CODE-7 | 正常系 | コードブロックは、ボタンと同じ色 (white、成功 green、失敗 red) の枠線で囲む               | `register.tsx`       |
| CODE-8 | 正常系 | 表は、枠線で囲まない                                                                      | `register.tsx`       |

## 3. 表の検出

| ID    | 区分   | 仕様                                                                                  | 実装          |
| ----- | ------ | ------------------------------------------------------------------------------------- | ------------- |
| TBL-1 | 正常系 | 表が始まる行から、表の文字列と次に読む行の位置を返す                                  | `findTableAt` |
| TBL-2 | 正常系 | 表が始まらない行は、undefined を返す                                                  | `findTableAt` |
| TBL-3 | 正常系 | 配置指定の区切り行 (`:--`、`--:`) と、外側の `\|` がない表も表にする                  | `findTableAt` |
| TBL-4 | 正常系 | 区切り行がまだない表と、区切り行が途中までの表は、表にしない (回答の生成途中への対応) | `findTableAt` |
| TBL-5 | 正常系 | 見出し行と区切り行の列数が違うものと、区切り行だけの水平線は、表にしない              | `findTableAt` |
| TBL-6 | 正常系 | 引用とリストの中の表は、表にしない                                                    | `findTableAt` |
| TBL-7 | 正常系 | 表の行は、空行か `\|` のない行で終わる                                                | `findTableAt` |
| TBL-8 | 正常系 | エスケープされた `\|` だけの見出し行は表にしない。`\\` の直後の `\|` は区切りにする  | `findTableAt` |

## 4. コードブロックの検出

| ID    | 区分   | 仕様                                                                                          | 実装                    |
| ----- | ------ | --------------------------------------------------------------------------------------------- | ----------------------- |
| BLK-1 | 正常系 | コードブロックが始まる行から、コードブロックの行とコードと次に読む行の位置を返す              | `findCodeBlockAt`       |
| BLK-2 | 正常系 | コードブロックが始まらない行は、undefined を返す                                              | `findCodeBlockAt`       |
| BLK-3 | 正常系 | 言語は区別せず、どの言語のコードブロックもコードブロックにする                                | `findCodeBlockAt`       |
| BLK-4 | 正常系 | バッククォートを含む行 (` ```code``` と書く` など) は、開始のフェンス行にしない               | `findCodeBlockAt`       |
| BLK-5 | 正常系 | 終了のフェンス行がないコードブロックは、回答の最後までをコードにする (回答の生成途中への対応) | `findCodeBlockAt`       |
| BLK-6 | 正常系 | 終了のフェンス行は、開始と同じ文字で、開始以上の長さの行にする                                | `findClosingFenceIndex` |
| BLK-7 | 正常系 | チルダ (`~~~`) のフェンス行も、コードブロックにする                                           | `findCodeBlockAt`       |
| BLK-8 | 正常系 | コードブロックの中の表も、コードにする                                                        | `findCodeBlockAt`       |

## 6. 回答の終了後の非表示

回答中は表示し、回答の終了後に非表示にする。回答は、メインの回答だけを数える (サブエージェントの回答は数えない)

| ID     | 区分   | 仕様                                                                                 | 実装                |
| ------ | ------ | ------------------------------------------------------------------------------------ | ------------------- |
| HID-1  | 正常系 | 回答中は、今の回答のツールの行 (ToolUse) を表示する                                  | `isToolShown`       |
| HID-2  | 正常系 | 回答の終了後は、ツールの行を非表示にする                                             | `endTurn`           |
| HID-3  | 正常系 | 次の回答が始まっても、前の回答のツールの行は表示に戻らない                           | `startTurn`         |
| HID-4  | 正常系 | ツールの結果の行 (ToolResult) も、回答中は表示し、回答の終了後は非表示にする         | `register.tsx`      |
| HID-5  | 正常系 | ツールのまとめの行 (ToolGroup) は、今の回答のツールを含む間だけ表示する              | `isToolGroupShown`  |
| HID-6  | 正常系 | 回答の所要時間の行 (TurnDuration) は、常に非表示にする                               | `register.tsx`      |
| HID-7  | 正常系 | ツールの進行の行 (ToolProgress) は、今の回答のツールの間だけ表示する                 | `isToolShown`       |
| HID-8  | 正常系 | 起動時のお知らせ (InfoNotice) は、最初の回答が終わるまで表示し、終わると非表示にする | `isInfoNoticeShown` |
| HID-9  | 正常系 | 全体表示 (ctrl+o) のときは、ToolUse、ToolResult、ToolGroup、TurnDuration を表示する。ToolProgress と InfoNotice は、全体表示かを判定できないため、表示できない | `register.tsx`      |
| HID-10 | 正常系 | サブエージェントの回答の開始と終了では、メインの回答中の状態を変えない               | `register.tsx`      |
| HID-11 | 正常系 | 中断やエラーで終わった回答のツールの行も、非表示にする                               | `endTurn`           |
| HID-12 | 正常系 | スラッシュコマンドの出力の行 (CommandOutput) は、回答の終了後も表示する              | `register.tsx`      |
| HID-13 | 正常系 | サブエージェントの行 (他のエージェントからのメッセージと、バックグラウンドタスクの通知の UserMessage) は、回答中は表示し、回答の終了後は非表示にする | `isAgentRowShown`   |
| HID-14 | 正常系 | 回答の開始前に描画した行も、その回答が始まれば表示する                               | `isAgentRowShown`   |
| HID-15 | 正常系 | 次の回答が始まっても、前の回答までに描画した行は表示に戻らない                       | `endTurn`           |
| HID-16 | 正常系 | サブエージェントの行も、全体表示 (ctrl+o) のときは表示する                           | `register.tsx`      |
| HID-17 | 正常系 | UserMessage の from と task がない、入力欄以外の行は、回答の終了後も表示する        | `register.tsx`      |

## 7. 折りたたみ

質問と回答を、1行目だけに折りたたむ。回答は、1チャット (1ターン) の全ブロックをまとめて1つに折りたたむ。直近のものと、手動で開いたものは開く

| ID     | 区分   | 仕様                                                                                         | 実装               |
| ------ | ------ | -------------------------------------------------------------------------------------------- | ------------------ |
| FTX-1  | 正常系 | 空でない行が2行以上あれば、複数行にする                                                      | `isMultiline`      |
| FTX-2  | 正常系 | 空でない行が1行なら、空行があっても複数行にしない                                            | `isMultiline`      |
| FTX-3  | 正常系 | 1行目は、最初の空でない行にする                                                              | `firstLineOf`      |
| FTX-4  | 正常系 | 1行目から、見出し、箇条書き、強調、バッククォートの記号を外す                                | `firstLineOf`      |
| FLD-1  | 正常系 | 直近2ターンの回答は開き、3ターン目が始まると最も古いものだけ閉じる                           | `startAnswerTurn`  |
| FLD-2  | 正常系 | 1ターンの複数のブロックは、最初のブロックだけが折りたたみの行を出す                          | `noteAnswerBlock`  |
| FLD-3  | 正常系 | 閉じた回答は、最初のブロックの1行目を緑 (`COLOR.green`) で表示する                           | `register.tsx`     |
| FLD-4  | 正常系 | 開いた回答は、橙 (`COLOR.orange`) の閉じるボタンの下に本文を表示する                         | `register.tsx`     |
| FLD-5  | 正常系 | 押して開いた回答は、次のターンでも開いたままにする。もう一度押すと閉じる                     | `toggleOpen`       |
| FLD-6  | 正常系 | 直近の回答でも、押して閉じたら閉じたままにする                                               | `isOpen`           |
| FLD-7  | 正常系 | 1行の回答は、折りたたまず緑 (`COLOR.green`) の文字で表示し、要約の回答は標準の描画にする     | `register.tsx`     |
| FLD-8  | 正常系 | 閉じた回答は、表とコードブロックのコピーボタンを表示しない                                   | `register.tsx`     |
| FLD-9  | 正常系 | 最後に表示した質問2件だけ開き、それより前の質問は青 (`COLOR.blue`) の1行目で閉じる           | `noteQuestionSeen` |
| FLD-10 | 正常系 | 押して開いた質問は、新しい質問が増えても開いたままにする                                     | `toggleOpen`       |
| FLD-11 | 正常系 | 入力欄以外の質問と全体表示 (ctrl+o) の質問は、折りたたまず標準の描画にする                   | `register.tsx`     |
| FLD-12 | 正常系 | 質問の開閉は、回答の開閉と連動しない                                                         | `register.tsx`     |
| FLD-13 | 正常系 | 開いたチャットは、閉じるボタン1つの下に、全ブロックの本文を順に表示する                      | `register.tsx`     |
| FLD-14 | 正常系 | チャット全体で2行以上になれば、1行のブロックも含めて折りたたむ                               | `isGroupFoldable`  |
| FLD-15 | 正常系 | 押すと、チャットの全ブロックをまとめて開閉する                                               | `toggleOpen`       |
| FLD-16 | 正常系 | 直近2チャットの回答は、複数のブロックがあってもまとめて数える                                | `startAnswerTurn`  |
| FLD-17 | 正常系 | ターンが分からない回答のブロックは、ブロックごとに折りたたむ                                 | `noteAnswerBlock`  |
| FLD-18 | 正常系 | 1行の質問は、折りたたまず青 (`COLOR.blue`) の文字で表示する                                  | `register.tsx`     |
| FLD-19 | 正常系 | 閉じた回答、閉じた質問、閉じるボタンは、横幅いっぱいまで文字を埋めて、余白も押せるようにする | `padLabelToRight`  |
| WID-1  | 正常系 | 半角の文字は1、全角の文字と絵文字は2と数える                                                 | `displayWidthOf`   |
| WID-2  | 正常系 | 結合文字と幅のない文字は、幅に数えない                                                       | `displayWidthOf`   |
| WID-3  | 正常系 | 文言の右側を、横幅から余白を引いた幅まで埋める                                               | `padLabelToRight`  |
